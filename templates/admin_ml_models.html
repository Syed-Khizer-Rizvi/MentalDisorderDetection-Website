Retrain the facial emotion model

Training runs on Kaggle's GPUs, not on this server. The app picks up a new model when Flask restarts.

  1. Open the training notebook on Kaggle.{% if m.kaggle_url %} Open notebook ↗{% else %} (No link is set yet: add KAGGLE_NOTEBOOK_URL to .env.){% endif %}
  2. Turn on the GPU accelerator and click "Run All". Training takes a while; wait for the final cell to write the model files.
  3. Download the outputs: fer_emotion_model.keras and model_metadata.json from the notebook's Output tab.
  4. Replace the two files in the Models/ folder of this project. Keep haarcascade_frontalface_default.xml; it isn't part of training.
  5. Restart Flask (stop it with Ctrl+C, then run python app.py). The model loads once at startup; if it fails to load, the console shows a warning and scans fall back to DeepFace.
  6. Come back to this page to check the new accuracy and that the status says Active.

The model file is stored with Git LFS, so commit it as usual and LFS handles the upload.
