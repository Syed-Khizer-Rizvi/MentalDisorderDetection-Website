What's recorded: sign-ins and sign-outs, failed sign-ins the server sees, account and doctor approval changes, wristband pairing, completed assessments, critical alerts, alert acknowledgements, and settings / ML changes. Page views aren't logged, and passwords, API keys and tokens never are.

Sign-in failures: a wrong password is rejected by Firebase in the browser before it reaches this server, so it isn't logged here. Logged failures are rejected tokens, unregistered accounts and doctors who aren't approved.

IP addresses are the direct connection address (shown as "localhost" in development). Behind a proxy they'd be the proxy's address.

Retention: logs are stored indefinitely. For production, consider periodic cleanup (e.g., retain 90 days).
